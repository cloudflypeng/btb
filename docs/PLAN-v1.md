# BTB v1 计划书：超越官方客户端的 B 站流媒体应用

> 状态：**待确认**。请在每个功能点前勾选 `[x]` 表示确认，`[-]` 表示砍掉，或直接在条目后写批注。
> 范围：先优化 iOS + macOS 共用的 SwiftUI 客户端（`Shared/` + `Mobile/` + `Mac/`）；全部确认、验收后再迁移 Android。
> 基线：v0.1.3（2026-11-26 发布）。

---

## 0. 定位：我们凭什么比官方好

官方客户端的问题主要不在功能，而在于：**广告与运营位多、启动重、首页信息噪音大、动效生硬且不可打断、iPad/Mac 体验敷衍、播放器手势与弹幕设置藏得深。**

BTB 的三条原则：

1. **内容即界面**：没有广告、开屏和运营弹窗，封面和视频本身就是主视觉，界面元素尽量退到后面。
2. **一切可打断**：所有转场都基于弹簧、跟手，可以在中途被抓住、反向或取消，不存在需要等它播完的动画。
3. **快于感知**：交互 100ms 内必有反馈，首帧画面 < 800ms；列表滚动在 120Hz 下不掉帧。

## 2. 功能点确认清单

优先级说明：**P0** 是 v1 必须完成的部分，**P1** 是强烈建议，**P2** 是加分项。工作量单位为人日，按 AI 辅助开发估算。

### A. 性能地基（P0，所有体验的前提）

- [ ] **A1 性能基线与度量**：用 `os_signpost` 埋点（冷启动、首页首屏、点击到首帧、滑动掉帧率），配合 Instruments 模板和一个 `make perf` 脚本输出报告。**验收：每个 PR 能对比前后数据。**（1d）
- [ ] **A2 图片管线重写**：用 ImageIO 按目标像素尺寸下采样（`kCGImageSourceThumbnailMaxPixelSize`），在后台解码；内存 LRU（按字节限额）+ 磁盘缓存（200MB 上限，可在设置中清理）；向 B 站图床请求 `@{w}w_{h}h.webp` 的尺寸后缀，按需取图。**验收：首页快速滑动 120Hz 掉帧 < 1%，内存峰值下降 40%+。**（2d）
- [ ] **A3 列表预取**：滚动方向前方 2 屏的封面提前下载并解码；分页提前 3 个项目触发（沿用已有契约）。（0.5d）
- [ ] **A4 拆分 AppModel**：按领域拆成 `FeedStore` / `PlayerStore` / `LibraryStore` / `MessageStore` / `AccountStore` / `SearchStore` 等，各自是独立的 `@Observable`；`AppModel` 只负责组装和路由。**验收：最大单文件 < 1000 行，页面之间不会互相触发刷新。**（3d，纯重构，行为不变）
- [ ] **A5 冷启动优化**：首页 feed 落盘缓存，启动时先展示上次内容（stale-while-revalidate）；bbcore 初始化与 UI 并行。**验收：冷启动到可交互 < 400ms（iPhone 15 级别设备）。**（1d）

### B. 秒开播放（P0，核心竞争力）

- [ ] **B1 预解析**：手指按下卡片（touch down / hover 300ms）时立即发起 `player.resolve`，结果缓存 60s。（1d）
- [ ] **B2 首帧占位**：播放器先显示已缓存的封面作为首帧，视频首帧到达后交叉淡入，过程中不出现黑屏。（0.5d）
- [ ] **B3 起播策略**：先用低码率快速起播，随后无缝切换到目标清晰度（AVPlayer `preferredPeakBitRate` 爬升，或由 bbcore 生成多档 variant）。**验收：点击到首帧 P50 < 800ms，P90 < 1.5s。**（2d，需要 bbcore 配合）
- [ ] **B4 续播与进度记忆**：本地记录每个视频的播放位置，卡片封面底部显示进度条，与云端历史合并。（1d）
- [ ] **B5 后台播放 / 锁屏控制 / 灵动岛**：`MPNowPlayingInfoCenter` + 远程指令；iOS 支持纯音频后台播放。（1d）
- [ ] **B6 画中画完善**：从列表上滑离开播放页时自动进入 PiP（iOS）；Mac 支持悬浮小窗。（1d）

### C. 动效与转场（P0，「丝滑」的主体）

- [ ] **C1 卡片 → 播放器的英雄转场**：封面从卡片位置放大成为播放器，详情内容从下方随弹簧滑入；下拉播放器时它会缩回原卡片位置（iOS 18 `navigationTransition(.zoom)`，iOS 17 用自研 matched geometry 兜底）。**验收：转场全程可被手势打断和反向。**（3d）
- [ ] **C2 统一动效 Token**：只保留 3 组弹簧：`snappy`（响应 0.3，阻尼 0.85）、`smooth`（0.45，1.0）、`bouncy`（0.5，0.7）。现有 easeOut 时长全部替换为这 3 组；开启「减弱动态效果」时降级为透明度变化。（0.5d）
- [ ] **C3 按压反馈**：卡片按下缩放到 0.97，带高光，松手回弹；长按弹出预览菜单（iOS `contextMenu` preview：静音自动播放片段 + 稍后再看/分享/不感兴趣）。（1d）
- [ ] **C4 触感反馈体系**：点赞、投币、收藏、切换分 P、拖动进度条到章节点、下拉刷新阈值等节点触发 `sensoryFeedback`；Mac 端使用触控板力反馈。（0.5d）
- [ ] **C5 一键三连动画**：长按点赞触发环形进度，完成后三个图标依次弹出并散开粒子；结果乐观更新，失败时回滚。（1d）
- [ ] **C6 列表入场与内容替换**：首屏卡片错峰淡入（间隔 30ms，只在首屏出现时播放）；数字变化用 `contentTransition(.numericText())`；Tab 切换时内容横向滑动并跟手。（1d）
- [ ] **C7 骨架屏与真实内容共用布局**：骨架和最终卡片尺寸完全一致，加载完成时原位淡入，不产生布局跳动。（0.5d）

### D. 播放器体验（P0/P1）

- [ ] **D1（P0）手势体系**：单击切换控件，双击暂停，左右滑动拖进度（带缩略图预览帧），左侧上下滑调亮度、右侧调音量，长按 2 倍速（可在设置中改倍率），双指捏合在填充与适应之间切换。（2d）
- [ ] **D2（P0）进度条缩略图**：使用 B 站 videoshot 雪碧图，拖动时显示画面预览，并标注章节和高能点。（1d）
- [ ] **D3（P0）弹幕引擎重写**：把逐条 `CATextLayer` 改为预渲染文字纹理 + 单个 Metal/CALayer 合成层，配合轨道分配算法防止重叠；支持 1000 条/屏不掉帧。**验收：高能段落 120Hz 稳定。**（3d）
- [ ] **D4（P1）弹幕增强**：智能防挡（基于 Vision 人像分割，在人物区域不绘制弹幕）、关键词与等级屏蔽、按密度自适应、发送弹幕。（2d）
- [ ] **D5（P1）横屏 / 全屏转场**：竖屏旋转为横屏时，画面从原位置平滑放大；支持竖屏视频的沉浸式全屏（上下滑切换下一个）。（1.5d）
- [ ] **D6（P1）字幕**：CC 字幕与 AI 字幕，支持双语和样式设置。（1d）
- [ ] **D7（P2）AV1 / HDR / 杜比视界**：支持的设备上自动选择，能耗优先策略可在设置中切换。（2d，依赖 bbcore）

### E. 信息架构与交互（P1）

- [ ] **E1 首页去噪**：推荐流可以「不感兴趣」，带原因选项；支持按时长和分区过滤；隐藏已看过的视频（开关）。（1d）
- [ ] **E2 稍后再看 / 下载队列快捷入口**：在任意卡片上左滑加入稍后再看，右滑下载（iOS swipe actions，Mac 用右键菜单）。（0.5d）
- [ ] **E3 迷你播放条**：离开播放页后在底部 Tab 上方保留一个可拖拽的迷你播放条，上滑回到全屏，下滑关闭。（1.5d）
- [ ] **E4 全局搜索面板**：Mac `⌘K` / iOS 下拉打开，统一搜索视频、UP、历史、收藏和设置项，结果实时出现。（1.5d）
- [ ] **E5 iPad 适配**：三栏布局（侧栏 / 列表 / 播放器），支持台前调度和多窗口；`TARGETED_DEVICE_FAMILY` 加入 iPad。（2d）
- [ ] **E6 Mac 专属**：全键盘操作（J/K/L、空格、←/→、F、D 弹幕开关、`[` `]` 调速）、菜单栏迷你播放器、多窗口独立播放。（2d）

### F. 超越官方的特色功能（P1/P2）

- [ ] **F1（P1）SponsorBlock 式跳过**：接入社区恰饭片段数据，自动或手动跳过并在进度条上标记。（1d）
- [ ] **F2（P1）听视频模式**：纯音频播放并关闭视频解码以省电，支持定时关闭。（0.5d）
- [ ] **F3（P1）智能离线**：Wi-Fi + 充电时自动下载稍后再看列表，可设置空间上限。（1d）
- [ ] **F4（P2）观看统计**：每周观看时长、偏好分区，以本地图表展示，数据不上传。（1d）
- [ ] **F5（P2）Widget / 快捷指令**：桌面小组件显示关注更新，App Intents 支持「继续播放」。（1.5d）
- [ ] **F6（P2）iCloud 同步设置**：屏蔽词、弹幕样式、播放偏好跨设备同步。（0.5d）

## 3. 性能验收指标（汇总）

| 指标 | 目标 | 测量方式 |
|---|---|---|
| 冷启动到可交互 | < 400ms | signpost，iPhone 15 / M1 |
| 点击到视频首帧 | P50 < 800ms，P90 < 1.5s | signpost，Wi-Fi |
| 首页滑动掉帧率 | < 1%（120Hz） | Instruments Hitches |
| 高能弹幕段落 | 120Hz 稳定，CPU < 30% | Instruments |
| 首页常驻内存 | < 150MB | Xcode Memory Gauge |
| 交互反馈 | 任意点击 < 100ms 有视觉/触觉响应 | 人工 + 录屏逐帧检查 |

## 4. 实施顺序（建议）

```
第 1 阶段  地基       A1 → A2 → A3 → A4 → A5        ≈ 7.5d
第 2 阶段  秒开播放   B1 → B2 → B3 → B4             ≈ 4.5d
第 3 阶段  丝滑动效   C2 → C7 → C3 → C1 → C4 → C5 → C6  ≈ 7.5d
第 4 阶段  播放器     D1 → D2 → D3 → B5 → B6         ≈ 8d
第 5 阶段  P1 特色    按确认结果排期
→ 验收通过后：Android 迁移（Compose 对应实现 + Media3 + 同一套动效 Token）
```

每个阶段结束时提交一次 PR，附带性能对比数据和录屏，你验收后再进入下一阶段。
